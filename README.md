# Blood Bank Management System

A Java-based application designed to manage blood donor registrations, check donor availability, and match requests efficiently.

## 🚀 Features
- **Donor Management:** Add, update, and search blood donor details.
- **Search & Filter:** Find available donors by blood group and location.
- **Data Access Object (DAO) Pattern:** Structured database and data handling layer.

## 🛠️ Tech Stack
- **Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
